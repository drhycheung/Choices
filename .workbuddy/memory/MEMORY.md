# Choices 项目长期备忘

## 项目定义
开源教育工具：文字交互式分支叙事模拟器。学生读故事→做选择→触发不同分支与结局。
核心引擎通用，场景作为独立数据包，可不断新增。首个场景=学生创业（植入国家安全/法律/伦理风险抉择），后续扩展实习、科研等。
- **中文名：一念之差**（英文代号 / 仓库名：Choices）。"一念之差"点题"每个选择都改变命运走向"，契合国家安全/法律/伦理风险抉择的教育立意。

## 硬性要求（已确认，按优先级）
1. **输出必须是静态站（最高优先级）**：无后端，可部署 GitHub Pages / 任意静态托管。零运维。
   → 直接排除 Streamlit（需 Python 服务端）及任何服务端依赖。运行时引擎必须纯 JS（浏览器跑）。
2. **选择 ↔ 结局必须存在确定性因果关系（硬要求）**：每个选择对状态变量有明确、可见、可追踪的效果（无随机骰子）；结局由累积状态阈值/条件门控触发。引擎须保证因果链可追溯（可生成"决策轨迹"展示给学生），并提供校验器证明：无死路、每个结局可达、每个选择确有非零效果。
3. 场景 = 独立 JSON 数据包，可插拔、持续新增（运行时 fetch 加载）。

## 软约束 / 已放宽项
- **反思层：可选**。老师可在课堂上口述补充，引擎不必强制要求反思字段（schema 中设为可选，缺省不阻断运行）。
- **场景内容由 AI 辅助生成**：作者把故事大纲交给 AI、产出合法 scenario JSON；因此 schema 须对 LLM 友好，且必须有校验器兜底。作者工作流不是瓶颈。

## 架构方向（推论）
- 运行时引擎跑在浏览器（JS），不依赖服务端。
- 场景为静态 JSON 文件（仓库内，运行时 fetch 加载），天然满足"独立数据包可插拔"。
- 教育追踪/反思：仅客户端（localStorage + 导出/导入 JSON），或可选后端（非必须）。
- dev 期可用 Python 做校验器/编译器（仅开发时，不进运行时）。
- 参考项目：引擎架构取 NetStrider/text-adventure-engine；场景 Schema 与教育层（反思题/多结局/变量评分）取 Liberty Park Scenario Engine 的 config.json 模式（但 Liberty Park 的 Streamlit 绑定不适合，仅作模板参考）。

## 文档约定
- README.md 与 docs/vibe-coding.md 一律用英文撰写（除项目中文名「一念之差」保留外，不出现任何中文解释性文字）。中文简释段落已删除；示例 JSON 中的 zh 字段值用 "…" 占位，不写真实中文。应用本身仍是中英双语（player.js 的 UI 文案与场景数据不受影响）。

## 关键决策记录
- 2026-10-08 调研同类开源项目：Ink(4963★,MIT) / Twine2(2904★,GPL-3.0) / ChoiceScript(461★) 为成熟创作工具；教育向数据驱动引擎（Liberty Park / NetStrider 等）均 0★，市场空白。结论：NetStrider 与 Liberty Park 互补，不二选一。
- 2026-10-08 确认"静态站必须" → 排除 Streamlit 服务端方案。
- 2026-10-08 评估 ViciousSquid/Adventure（7★,MIT,Python+PWA）：虽有 PWA 可部署 GitHub Pages（满足静态要求），但 TTRPG 随机骰子机制与"教育确定性评分"冲突、场景为 .zip 不如纯 JSON 透明、无教育层、Z-Machine/Glulx 复古导出对教育目标无价值 → 仅作"静态部署可行性"参考，不采纳为基础。
- 2026-10-08 需求细化（23:1x）：用户确认——①静态站为最高优先级；②"选择↔结局必有因果关系"为硬要求（确定性、可追踪、无随机）；③反思层可选（老师课堂补充，引擎不强求）；④场景内容由 AI 辅助生成、作者工作流非瓶颈。→ 架构锁死为"纯 JS 静态引擎 + 独立 JSON 场景数据包 + 因果确定性评分 + 路径/因果校验器"，反思字段设为 schema 可选。
