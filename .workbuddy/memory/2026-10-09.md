### 故事线改造方案：双轨计分（已提案，待用户拍板）
- 用户要求：故事既要有国安/伦理，也要有创业挑战（Lean Canvas 考量），不止"选最保守的"。
- 核心提案 **双轨计分**：风险轨 3 维（national_security/legal/ethics，愈低愈好）+ 创业轨 3 维（问题–方案契合 Canvas1-4 / 商业模式 Canvas5-7 / 护城河与指标 Canvas8-9，愈高愈好）。结局改为 2×2 象限（可持续成功 / 合规但停摆 / 爆雷式增长 / 双输），每象限再按触发维度细分。
- 关键发现（技术）：engine.js 与 validate.js 完全不认识"风险"语义，扩到 6 维**无需改动**。
- **必须先修的坑**：scenario JSON 声明了 `higherIsRisk`，但 player.js `renderDims()` 从未读取——目前硬编码 `ratio>=0.5` 即红色危险。直接加正向维度会出现"越强越红"。需按 higherIsRisk 分两套配色。
- 计划启用闲置能力：`requirements`（按维度解锁选项），例如合规审计选项要求商业模式分够高。
- 建议故事载体：AI 健康/运动 App（对应 L05 的 Strava/位置数据案例）。四幕 = Canvas 阶段 × AI 生命周期（数据收集→模型训练→部署决策→社会外溢）。
- reflection 对齐反思论文评核三项：识别议题+引用法条 / 持份者分析 / 缓解策略。
- 风险点：HUD 由 3 条变 6 条后手机端过高，需分组（RISK / VENTURE）并实机验证。
- 尚未动代码，等用户确认范围（阶段 A 只改文本 / B 双轨全量 / C 加 Canvas 回顾卡）。
